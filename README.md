# Portfolio

Static single-page portfolio. No build step, no dependencies.

- `index.html`: the whole site (HTML, CSS, JS inline)
- `og.png`: link-preview image (1200x630)
- `vercel.json`: security headers and clean URLs

Before sharing, search `index.html` for `YOUR-SITE` and replace it with the real domain.
Links (GitHub, Hugging Face, writing) are set in the `CFG` object near the bottom of the script.

Do not commit client data, model weights or anything covered by an employer agreement.
